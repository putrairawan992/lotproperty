# PROMPT FIGMA MAKE — LOT PROPERTY GAMIFICATION PLATFORM (LIGHT & DARK MODE)

Design a modern, premium gamification ecosystem for a property agent platform called **LOT Property**.

Create complete responsive UI in both **Light Mode** and **Dark Mode**.

## DESIGN GOAL

This is NOT a typical CRM dashboard.

The experience should feel like:

* Duolingo Gamification
* LinkedIn Achievement System
* League of Legends Profile Progression
* Clash Royale Reward System
* Luxury Gaming Platform
* Premium Fintech Experience

Every screen must motivate agents to:

* earn XP
* level up
* unlock badges
* appear on Hall of Fame
* compete on leaderboard
* complete quests

The design must create a feeling of:

* Prestige
* Progress
* Competition
* Achievement
* Status
* Exclusivity
